# Known Gaps & Follow-ups

Open mismatches, placeholders, mocks and tech debt found while working on this project. Each item
lists where it lives, why it matters, and the proposed fix.

**Rules:** before starting work, check this file for items in the area you're touching. If your
change touches a listed area, resolve that item in the same change and delete it when fully fixed.
Never build new features on top of a listed gap. Log anything you find but can't fix now here —
a mention only in chat or a PR description is not enough.

Status key: 🔴 blocks production use · 🟠 wrong/inconsistent behaviour · 🟡 polish / tech debt
