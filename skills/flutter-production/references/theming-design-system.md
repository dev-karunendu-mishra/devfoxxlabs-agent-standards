# Theming & Design System

## Structure

```text
core/theme/
  app_colors.dart                # raw palette constants (brand, neutrals, semantic) — only file with Color(0x…)
  app_theme.dart                 # AppTheme.lightTheme / AppTheme.darkTheme (Material 3)
  <app>_theme_extension.dart     # ThemeExtension: brand + semantic + status tokens (light & dark consts)
  app_theme_mode.dart            # enum AppThemeMode { system, light, dark } + label/description/icon/code
  theme_repository.dart          # SecureThemeRepository (flutter_secure_storage, 2 s timeout) + FakeThemeRepository
  theme_provider.dart            # ThemeModeNotifier (restore/set/toggle) + themeModeProvider (ThemeMode)
  widgets/theme_mode_selector    # bottom sheet with System / Light / Dark choice cards
```

## Rules

- `ThemeData(useMaterial3: true)` with a **fully specified** `ColorScheme` for both
  light and dark (primary, onPrimary, primaryContainer, secondary, surface, onSurface,
  surfaceContainer*, onSurfaceVariant, outline, outlineVariant, error*). Stock widgets
  (dialogs, pickers, snackbars, text selection) must never fall back to default purple
  or flash white in dark mode.
- Feature code reads colors only from `Theme.of(context).colorScheme` or
  `Theme.of(context).extension<AppThemeColors>()!`, or a `context` extension such as
  `context.appColors` / `context.isDarkMode`. **No `Color(0x…)` or `Colors.xyz`
  literals in features** (except `Colors.transparent` and white/black over hero images).
- Define these once in `AppTheme`:
  - `appBarTheme`: elevation 0, `scrolledUnderElevation: 0`, transparent status bar,
    correct `systemOverlayStyle` per brightness.
  - `cardTheme`: elevation 0, radius 16, 1 px `outline` border, `clipBehavior: antiAlias`.
  - `elevated/filled/outlined/textButtonTheme`: radius 12, min height 52, w700 16 sp
    labels, rounded rectangles (see the UI rules).
  - `inputDecorationTheme`: filled, padding 16/16, radius 12, focused border in primary,
    error border in error.
  - `pageTransitionsTheme`: `SlidePageTransitionsBuilder()` for every `TargetPlatform`.
  - `bottomSheetTheme`, `dialogTheme`, `snackBarTheme` (`behavior: floating`), `dividerTheme`.
- The `ThemeExtension` carries domain tokens: `success/warning/info/error` with matching
  `Container` and `Text` variants, booking or order status colors, `surfaceSecondary`,
  `surfaceElevated`, `borderSubtle`, `textTertiary`, `brandSoft/strong`. Implement
  `copyWith` and `lerp`.
- Theme choice: **System** (default), **Light** or **Dark**, persisted with the
  `app_theme_mode` key in secure storage. `restoreTheme()` runs on splash.
- Typography: the system font or one brand font (`google_fonts` only if the brand needs
  it, and bundle the font for offline use). Use a `TextTheme` defined once. Titles w700
  with slight negative letter-spacing.
- Assets are WebP. Logo variants are `logo.webp`, `<brand>_wordmark_dark.webp` and
  `<brand>_wordmark_white.webp`. Never add borders or shadows to the logo.

## Icons

- `hugeicons` is the primary set: `HugeIcon(icon: HugeIcons.strokeRoundedHome01, size: 24, color: cs.onSurface)`.
  Material `Icons.*_rounded` is acceptable where Hugeicons lacks one. Keep one style per screen.
- When the web admin stores icon names (e.g. `hugeicons:Home01Icon`), map them through a
  generated registry (`core/icons/hugeicons_registry.g.dart`, generated by a script in
  `tool/`) with a generic fallback icon for unknown names.

## Formatting (India defaults)

- Currency: `NumberFormat.currency(locale: 'en_IN', symbol: '₹', decimalDigits: 0 or 2)`,
  through a shared formatter. Never string-concat `'₹' + x`. Apps with a configurable
  currency pass the symbol from settings.
- Dates: shared helpers in `core/utils/date_formatting.dart` (`d MMM yyyy`, `h:mm a`).
  Store UTC and display local time.
- Strings: new apps that need Hindi or other languages use ARB files + `flutter gen-l10n`.
  Keep user-facing strings out of logic either way, with no string concatenation for
  sentences.
